# Reaction-Diffusion Patterns

A Python implementation of the **Gray-Scott reaction-diffusion model**, developed during the **McGill Hackathon**.

The program simulates two interacting chemical components using discrete diffusion and reaction equations, producing emergent patterns such as spirals, bacteria-like structures, and animal-inspired textures.

## Features

* Gray-Scott reaction-diffusion simulation
* NumPy-based numerical computation
* Matplotlib visualization and animation
* Preset parameters for different patterns

## Requirements

```bash
pip install numpy matplotlib
```

## Usage

Run the Python script and select a predefined pattern by changing:

```python
pattern = cheetah
```

The program displays both the evolution of the pattern and its final state.
